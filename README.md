# 数据授权与禁发控制（黄金预期差复盘服务）

为新闻生产管理数据使用权与发布边界：来源合同版本、可用栏目/地区/渠道、署名格式、
原始数据与衍生图表谱系、决议禁发时点与法务例外。编辑创建素材（文章版本）时即获得
针对计划发布时间与发布渠道的可用性判断；服务不输出行情结论或交易建议。

服务通过 HTTP 接口交换业务事件，并使用 SQLite 文件保存本地状态。监听端口由
`PORT` 指定，数据文件位置由 `DATABASE_PATH` 指定；`contracts/entities.json`
记录稳定字段，`fixtures/example.json` 提供不含真实身份信息的示例，
领域与接口说明见 `docs/domain.md`、`docs/licensing.md`。

## 本地开发

运行 `make migrate` 初始化数据文件，`make test` 执行自动化检查，`make run`
启动服务。也可以使用 `docker compose up --build` 构建并运行容器，宿主机端口
通过 `APP_PORT` 调整。

## 能力一览

- 合同新版本（收窄/扩宽）自动作废旧版本，评估一律依据来源当前合同；
- 禁发改期/解除、来源撤回只追加事实，每次变化生成新的审查轮次，历史可查；
- 仅文章当前版本实际引用的素材占用授权额度，草稿不占额、多渠道不重复计数；
- 法务放行凭证内嵌签发当时的完整规则快照（`snapshot_digest`），事后规则变化不改凭证；
- 已发布页面只走补署名/替换/下架处置，文章报告列出许可依据、署名与未闭环渠道处置。
