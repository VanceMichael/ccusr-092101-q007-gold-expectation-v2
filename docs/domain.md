# 领域约定

政策预期、实际决定、市场价格与资金流数据按事件时间和可见时间保存。

外部主体一律使用不含真实身份信息的引用编号，时间采用带偏移量的 ISO 8601 字符串，附件只记录受控引用或 `sha256` 摘要。业务事件需要携带来源与序列号，后续实现应保留来源系统对事实的责任边界。

## 数据授权与禁发

- 服务只管理使用权与发布边界，不产生行情结论或交易建议。
- 现货、期货、利率、油价、官方购金素材各自保留原时区（`tz_name`）、原计量单位（`unit`）、事件时间与取得时间；系统不做单位归一化结论。
- 合同版本、禁发时点、例外批准、审查轮次、放行凭证均为追加式事实：合同收窄、来源撤回、发布时间变动只能生成新的审查结果，不覆盖旧结果。
- 评估依据来源当前有效合同；素材同时保留取得时锁定的合同版本。
- 仅被文章当前版本实际引用的素材/图表占用授权额度；放行凭证必须固定签发当时的完整规则与快照摘要。
- 已发布页面不被规则变化改写，只能进入补署名、替换或下架处置流程。
