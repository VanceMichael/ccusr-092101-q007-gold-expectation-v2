# 领域约定

政策预期、实际决定、市场价格与资金流数据按事件时间和可见时间保存。

外部主体一律使用不含真实身份信息的引用编号，时间采用带偏移量的 ISO 8601 字符串，附件只记录受控引用或 `sha256` 摘要。业务事件需要携带来源与序列号，后续实现应保留来源系统对事实的责任边界。

## 数据授权与禁发控制

新闻生产中的数据使用权独立于行情事实本身管理。服务边界是：**只记录使用权与发布边界，不产出行情结论或交易建议**；任何携带此类语义字段（如 `recommendation`、`forecast`、`signal`）的请求都在入口被拒绝。

### 核心对象

- **来源（source）**：行情终端、公开声明、研究机构限时材料、官方购金材料等，以引用编号标识，可整体撤回。
- **合同版本（contract version）**：记录可用栏目、可用地区、可用渠道、署名格式与授权额度。版本只增不改：合同收窄（渠道/栏目/地区缩减、额度下调、有效期提前）登记为新版本。
- **素材（material）**：现货（spot）、期货（futures）、利率（rates）、油价（oil）、官方购金（official_purchase）。各自保留原时区偏移、`timezone` 标签、计量单位与取得时间；服务不做数值加工。
- **衍生图表（derivative）**：通过 `parents` 固定与原始素材的派生关系；多人同时编辑只产生编辑记录，不占用授权额度。
- **禁发（embargo）与例外批准（approval）**：禁发时点按来源、素材类型、渠道、地区作用域匹配；例外批准由法务给出，可限定渠道/栏目/地区与有效期。

### 审查结果只增不改

编辑创建素材或图表时即可携带计划发布时间、渠道、栏目、地区进行审查，得到 `allowed`/`blocked`、阻断原因代码与应展示署名。合同收窄、来源撤回、禁发新增或发布时间变动**不会改写历史结果**，而是针对相关素材与衍生图表追加新的审查记录：

- 草稿版本只获得新的可用性判断；
- 已发布页面受阻时，按渠道开立处置单——授权类阻断走 **下架（takedown）**，仅署名问题走 **补署名（add_attribution）**，另有手工 **替换（replace）**；
- 处置单按 文章+渠道+素材+动作 去重，闭环前持续出现在文章合规清单中。

### 额度、凭证与合规清单

- 授权额度只统计**已发布文章版本实际引用**的原始素材（衍生图表展开到 `parents`）；编辑行为与草稿不占用额度。发布时对额度做最终核算，拦截并发签发后超额发布。
- 法务放行凭证（voucher）在签发时对全部 引用×渠道 重新审查，并在 `rule_snapshot` 中固定当时的合同版本、来源状态、禁发与审查编号。签发后规则变化使凭证失效，必须重新签发；凭证快照本身不被修改，供事后审计。
- `GET /articles/{article_ref}/compliance` 汇总任一文章所用数据的许可依据（来源、合同及版本）、应展示署名与尚未闭环的渠道处置。
